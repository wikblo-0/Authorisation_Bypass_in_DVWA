This repository stores the payloads used in the penetration testing of the Authorisation Bypass vulnerability in Damn Vulnerable Web Application (DVWA).

- low_medium_high_security_levels.sh contains an executable shell script used for automating attacks on the low, medium and high security levels.

You can read more about the attack in the blog linked below, and there you will also find YouTube videos showing a screencast of each attack.

https://pentesting-dvwa.hashnode.dev/
